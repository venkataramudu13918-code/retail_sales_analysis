# Retail Sales Analysis

A retail sales analysis repository containing SQL database scripts (`retail_sales_db.sql`) and spreadsheet reporting (`sales report.xlsx`) to explore sales performance and business metrics.

## Overview
This project (`retail_sales_analysis`) organizes structured SQL queries/database definitions alongside an Excel sales report for analyzing retail sales data and generating clear summaries.

## Repository Files
- `retail_sales_db.sql` — SQL script containing database schema, sample/retail sales data, and analytical queries
- `sales report.xlsx` — Excel workbook with sales figures, summaries, and reporting tables
- `README.md` — Documentation and usage guide

## Tools & Technologies
- **Database & Querying:** SQL (MySQL / relational SQL)
- **Spreadsheets & Reporting:** Microsoft Excel (`.xlsx`)
- **Version Control:** Git & GitHub
